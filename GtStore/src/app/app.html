Angular signals, in action

Signals are reactive values. When a signal changes, Angular updates the parts of the screen that read it.

A tiny cart example

{{ productName }}

Price: ${{ unitPrice.toFixed(2) }} each

Quantity
{{ quantity() }}
@if (quantity() === maxQuantity) {

You've reached the limit of {{ maxQuantity }} items.

}

Subtotal

${{ subtotal().toFixed(2) }} {{ quantity() }} × ${{ unitPrice.toFixed(2) }}

What to notice

1. A signal stores state

quantity = signal(1);

Read it by calling it: quantity(). The template does this to show the quantity.

2. Update the value

quantity.update(current => current + 1);

update() uses the previous value. Use set(1) when you already know the value.

3. Derive values with computed

subtotal = computed(
  () => quantity() * unitPrice
);

computed() tracks the signals it reads and recalculates when they change. It is read-only and cached until then.

What about effect()? Use effects for side effects, such as synchronizing with browser storage. For values derived from other state, prefer computed().
